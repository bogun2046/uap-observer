# G6 冻结验收用例

- 冻结标准编号：`G6-FROZEN-20260819-01`
- 前置条件：G5 通过；使用全新 PostgreSQL、对象存储和业务角色；不复用开发者本地结果。
- 独立性：实现人员只能提交自检和证据，最终结论由独立验收人员填写。

## G6-01 输入边界与追溯

- 操作：从 `extract_document` 任务追踪 `document_version -> artifact_version -> stored_object -> extraction -> derived stored_object`。
- 预期：每个输入、任务 attempt、输出和对象均可反查；提取器无外网访问，也不写 `public` 或 raw artifact。

## G6-02 HTML 确定性提取

- 操作：对包含导航、脚本、重复模板、实体编码和多段正文的固定 HTML 执行两次。
- 预期：正文顺序稳定，噪声被移除，标题/作者/语言按规则提取；两次输出哈希和 `location_map` 完全一致。

## G6-03 PDF 与字幕定位

- 操作：分别处理带文本 PDF、不可提取 PDF、WebVTT 和 SRT 固定夹具。
- 预期：PDF 成功结果带页码定位；不可提取输入进入结构化失败；字幕保留顺序和毫秒时间区间；非法时间轴不产生成功结果。

## G6-04 版本追加与哈希

- 操作：对同一 `document_version` 使用同一 extractor 重跑，再使用新 extractor 版本运行。
- 预期：同版本同输出只保留一个逻辑结果；新版本追加新结果；历史成功结果不被覆盖；正文哈希与对象清单一致。

## G6-05 并发幂等与对象一致性

- 操作：两个真实 Worker 并发处理相同文档版本，并注入数据库失败、对象存储失败和登记竞态。
- 预期：最多一个逻辑 extraction 和一个 derived 物理对象；失败不留下未登记对象；重试和一致性扫描不会误删在途对象。

## G6-06 任务状态与租约

- 操作：验证成功、解析失败、超限、可重试 I/O 失败、达到最大次数和租约过期后的处理。
- 预期：source/document 业务记录不承担任务状态；attempt、job、retry_wait、dead 和 recovery_reason 与 WP4 一致；迟到 Worker 不能提交旧结果。

## G6-07 安全与资源上限

- 操作：提交超大输入、压缩炸弹/异常 PDF、恶意 HTML、超长字幕和含敏感内容的失败路径。
- 预期：在资源上限内拒绝或失败收口；无原文泄漏到日志、错误摘要、公开表或镜像层；普通 Worker 只能访问允许的文档/对象边界。

## G6-08 交付物一致性

- 操作：全新环境执行迁移、权限、静态检查、全量测试、运行态探针和证据清单校验。
- 预期：迁移链唯一且幂等；G5 回归仍通过；G6 证据文件逐项哈希通过；Draft PR 的 quality、security、integration、gate 全绿。

## 门禁

G6-01 至 G6-08 必须全部通过。任一失败，登记为“独立验收不通过，待整改后复验”，WP7 门禁保持关闭。
